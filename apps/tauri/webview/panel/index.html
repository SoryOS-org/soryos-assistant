    About Sprite Assistant

    Desktop control panel for the Sprite voice assistant: live STT state, MCP host telemetry, and runtime controls.

    Highlights

    • Speech pipeline - Wake word + PTT capture into Whisper; preload banners keep STT asset downloads visible.
    • MCP host - Built-in stdio host with lifecycle telemetry and registry view; edit `mcp.config.json` from here.
    • Control panel - Chat with MCP rail, config editor, preferences (personality + allowlist), latency HUD, and log tail.
    • Durable state - Preferences, conversation memory, and app allowlists persist per machine in the worker state store.
